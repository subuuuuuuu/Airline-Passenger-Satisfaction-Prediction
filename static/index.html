Model Performance Analysis

The model is a Random Forest Classifier optimized using GridSearchCV (3-fold cross-validation) on a dataset of 103,904 airline passenger satisfaction records.

Key Achievements:

  • Highly Balanced Predictor: Maintained high precision (96.9%) and recall (94.5%), meaning both satisfied and dissatisfied passengers are correctly classified without severe bias.
  • Effective Handling of Outliers: Missing values in Arrival Delay were imputed using the median, and extreme outlier records were removed using customized distance and delay thresholds.
  • Feature Scaling: All ratings and numerical characteristics were normalized using StandardScaler to prevent delay values from dominating the distance metrics.

Random Forest Hyperparameters:

  • n_estimators: 100
  • max_depth: 20
  • min_samples_split: 5
  • min_samples_leaf: 1
  • bootstrap: True
